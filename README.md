# ERTH Labs

A series of Excel labs from ERTH 2001 (Planet Earth) at CU Boulder, reproduced in Python. Each lab lives in its own folder with a Jupyter notebook. The original work was completed in Excel for class; these notebooks recast the same calculations so the labs can sit together as a portfolio project.

This is a personal conversion of labs already completed. It is not a submission of answers for the course.

## Labs

1. [Lab 1 — Earth's Density: Constraining Planetary Interiors](lab01-earth-density/) — four-shell models of Earth, volume-weighted average density, and a mass check against the real planet.
2. [Lab 2 — GPS Plate Motion](lab02-gps-plate-motion/) — north and east components from GPS time series, five-year horizontal rates, and a comparison of stations across the San Andreas system.

AI used: Python notebooks built with help from an AI coding agent.
